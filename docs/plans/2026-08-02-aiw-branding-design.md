# AIW Branding Design

## Purpose

Present the project as **SkillsMP Research by AIW** without changing its technical identity. `AIW` acts as a restrained quality mark; `skillsmp-search` remains the repository, package, skill, command, and installation name.

## Public promise

SkillsMP Research searches SkillsMP, reads the source of promising skills, removes weak or duplicate candidates, and recommends the ones worth using.

## Presentation

- Change the README heading to `SkillsMP Research by AIW`.
- Keep the approved slogan directly below the badges.
- Change the hero and social-preview title to `SKILLSMP RESEARCH` and add a smaller `by AIW` signature.
- Preserve the existing arcade-style visual, workflow illustration, palette, and dimensions.
- Mention once that this is an independent project which uses SkillsMP but is not affiliated with or endorsed by SkillsMP. Keep that note close to the introduction and out of the main pitch.

## Boundaries

- Do not rename `skillsmp-search`, its paths, package metadata, scripts, commands, or install examples.
- Do not repeat `AIW` across feature copy, examples, or technical documentation.
- Do not imply official SkillsMP affiliation.
- Do not add inflated claims, AI-shaped filler, or implementation details that do not affect users.
- Do not push, tag, publish a release, or change GitHub settings in this pass.

- Inspect both raster assets at full size and confirm their existing dimensions.

- Run the test suite, repository validator, and skill validator.
- Scan the current tree and reachable history for secrets, personal information, and absolute local paths without printing sensitive values.
